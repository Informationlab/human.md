# HUMAN.md

**A portable context file for humans working with AI agents.**

HUMAN.md explores a simple question:

> If AI agents have `AGENTS.md`, skills, memory, tools and persistent context, what is the equivalent interface for the human they work with?

The proposal is a portable, human-readable description of **how to work with me** — communication, decision-making, autonomy, collaboration preferences, boundaries and relevant context.

See [`HUMAN.md`](HUMAN.md) for the full concept, specification, examples, related projects and open questions.

## Related projects

- [thellmwhisperer/human.md](https://github.com/thellmwhisperer/human.md) — human/agent collaboration and usage guardrails.
- [Intuition-Lab/personal-model](https://github.com/Intuition-Lab/personal-model) — evolving personal context shared across AI clients.
- [Spacebot](https://github.com/spacedriveapp/spacebot) — `HUMAN.md` as stable human context within an agent organisation.
- [Blank Collar](https://www.blankcollar.me/) — agent-readable professional human identity.

This project explores **HUMAN.md as a portable collaboration interface between a human and AI teams**.
